# sss-wallpaper

ユーザータイプは自分。複数のスクリーンをWindows PCにつないでいる。

1. Activity
2. Task
3. Walking Skeleton
4. ランダム表示

- 準備
  - 起動
    - [x] ウィンドウありで起動
      - [x] ウィンドウなし起動オプションでは、フォルダからランダムに選んで書き変えて自動終了する。
- 表示
  - ウィンドウ表示
    - [x] 全モニターの枠が左から右へ表示
      - [x] モニターのサイズと向きが枠に反映される
      - [x] 現在の壁紙がサムネイルで表示される。
  - エラー表示
    - [x] v 読み書きに失敗すると、エラーダイアログで知らせる。設定ファイルが壊れていても、枠は表示される。
- 壁紙設定
  - 変更
    - [x] ファイルを枠へドロップすると、PCの壁紙にすぐ反映される。
      - [x] フォルダを枠へドロップすると、フォルダが登録される。
  - 場所を開く
    - [x] v 枠のボタンで、登録したフォルダか、画像のあるフォルダをエクスプローラーで開く。
  - 設定
    - [x] 縦横比固定でFitするように表示。左寄せ、右寄せを選べる。白色で埋める。
      - [x] 埋める色を白か黒か選べる。
    - [x] v 設定はモニターごとに保存され、次の起動でも使われる。
  - ランダム
    - [x] v ランダム変更ボタンを押すとすぐにフォルダからランダマイズで登録される。
