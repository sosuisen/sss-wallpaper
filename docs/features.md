# 機能一覧

テストを要約した機能の一覧である。階層は`storymap.md`のアクティビティとタスクに沿う。

## 準備

- 起動
  - ウィンドウありで起動する
    - オプションがないとき、ウィンドウありで起動する
    - 最初に開くViewは、`FIRST_VIEW`定数で決まる
    - AtlantaFXのPrimer Lightテーマを使う
    - ウィンドウは、OSのタイトルバーのないEXTENDEDで表示し、HeaderBarにタイトルを出す
  - ウィンドウなしで起動する
    - `--randomize`オプションがあるとき、ウィンドウなしで起動する
    - 全モニターの壁紙を、登録フォルダからランダムに変えて終わる

## 表示

- ウィンドウ表示
  - モニターの枠を並べる
    - 枠はモニターの数だけ、左から順に並ぶ
    - 左端のx座標が同じモニターは、上から順に並ぶ
    - 枠には、左から順に1からの番号が付く
  - 枠の大きさ
    - 枠の大きさは、モニターの大きさに比例する。縦置きのモニターの枠は縦長になる
    - モニターが多いとき、枠の合計幅は決まった幅に収まる
  - 現在の壁紙
    - 起動時に、各モニターの現在の壁紙を読み込み、枠のサムネイルに表示する
    - 壁紙が設定されていないモニターでは、サムネイルは空である
    - 壁紙を変えると、サムネイルも変わる
  - 壁紙の元の名前
    - フォルダを登録した枠には、フォルダの名前を表示する
    - フォルダがなく画像だけの枠には、画像のファイル名を表示する
    - ドライブのルートを登録した枠には、ルートのパスを表示する
    - フォルダも画像もない枠には、何も表示しない
- エラー表示
  - エラーダイアログ
    - FXスレッドで回復できないエラーが起きると、そのメッセージをダイアログに表示する。ウィンドウは開いたままである
    - 想定外の例外が起きると、スタックトレースを読み取り専用でダイアログに表示する
    - ダイアログのメッセージは、展開可能な領域に初期状態で展開して表示する
    - ダイアログを閉じたときの処理を指定できる。ウィンドウなしの起動では、閉じると終了コード1で終わる
    - 回復できないエラーのメッセージは、空にできない
  - 起動時のエラー
    - 設定を読み込めないとき、エラーダイアログを表示する。モニターの枠は既定の設定で表示する
  - 読み書きのエラー
    - 設定ファイルに書き込めないときと、設定ファイルが壊れているときは、エラーになる
    - 画像として読めないファイルや、消された画像を合成しようとすると、エラーになる
    - 合成した画像を保存できないときは、エラーになる
    - フォルダが読めないときは、エラーになる
    - COMの呼び出しが失敗したときは、エラーになる

## 壁紙設定

- 変更
  - 画像をドロップする
    - モニターの大きさと寄せ方、埋める色で合成した画像を、壁紙に設定する
    - 画像ではないファイルだけをドロップしても、壁紙は変わらない
    - フォルダを登録した枠に画像をドロップすると、フォルダの登録を解除する
    - 画像を合成できないとき、元の画像もフォルダの登録も変わらず、保存もしない
  - フォルダをドロップする
    - フォルダを、そのモニターのフォルダとして登録する
    - フォルダの中からランダムに選んだ1枚を、壁紙に設定する
    - 画像のないフォルダは登録するが、壁紙は変えない
    - フォルダから画像を選べないとき、フォルダを登録しない
- 場所を開く
  - 「場所を開く」ボタンを押す
    - フォルダを登録した枠では、そのフォルダを開く
    - 画像だけの枠では、画像のあるフォルダを開く
    - フォルダも画像もない枠では、「場所を開く」ボタンを押せない
- 設定
  - 寄せ方
    - 寄せ方は左寄せと右寄せから選べる。既定は左寄せである
    - 寄せ方を変えると、前回の元の画像で壁紙を作り直す。再起動したあとでも作り直す
    - ドロップする前に寄せ方を変えても、壁紙は変わらない
  - 埋める色
    - 埋める色は白と黒から選べる。既定は白である
    - 埋める色を変えると、前回の元の画像で壁紙を作り直す
  - 画像の合成
    - 縦横比を保ったまま、モニターに収まるように縮小する
    - 左寄せでは左端に、右寄せでは右端に置く。上下は中央に置く
    - 合成した画像は、モニターと同じ大きさのPNGファイルとして保存する
    - 同じモニターの古い合成画像は、新しい画像を作るときに消す。ほかのモニターの合成画像は消さない
  - 設定の保存
    - フォルダ、元の画像、寄せ方、埋める色を、モニターごとに保存する
    - 保存した設定は、読み込むと同じ内容で戻る
    - 起動時に、保存した設定を各モニターに読み込む。読み込んでも壁紙は変えない
    - 設定ファイルがないとき、設定は空である
    - 埋める色が保存されていない古い設定ファイルでは、埋める色は白である
- ランダム
  - ランダム変更ボタンを押す
    - フォルダを登録した全モニターの壁紙を、左から順に、それぞれのフォルダからランダムに選んだ画像に変える
    - フォルダを登録していないモニターの壁紙は変えない
    - 選んだ画像は、壁紙を変える前に、元の画像として保存する
    - どのフォルダからも画像を選べなかったとき、設定は保存せず、壁紙も変えない
    - 変わったモニターのサムネイルと、元の画像の名前を更新する
    - ボタンは、ウィンドウの左右中央に置く

## Windowsとの連携

- FFMでIDesktopWallpaperを呼ぶ
  - 実機のモニター一覧を取得できる
  - 設定した壁紙を、そのモニターの壁紙として読み戻せる
