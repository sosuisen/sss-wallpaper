# plans

## 準備 > 起動 > ウィンドウありで起動

- [x] アプリを起動すると、FIRST_VIEW定数で指定したViewのウィンドウが表示される

## 表示 > ウィンドウ表示 > 全モニターの枠が左から右へ表示

- [x] モニター一覧は、左端のx座標が小さい順に並ぶ
- [x] モニターの数だけ、枠が左から順に表示される
- [x] 実機のモニター一覧を、FFMで1件以上取得できる
- [x] COMの呼び出しが失敗したとき（HRESULTが負）、WallpaperExceptionを投げる

## 壁紙設定 > 変更 > ファイルを枠へドロップすると、PCの壁紙にすぐ反映される

- [x] 画像ファイルを枠にドロップすると、そのモニターの壁紙に設定される
- [x] 画像ではないファイルだけがドロップされたとき、壁紙は変わらない
- [x] FFMで設定した壁紙が、そのモニターの壁紙として読み戻せる（実機の壁紙を変えるので、手動で実行する）

## 壁紙設定 > 設定 > 縦横比固定でFitするように表示。左寄せ、右寄せを選べる

- [x] 縦長の画像を横長のモニターへ左寄せでFitすると、画像は左端に置かれ、残りは白になる
- [x] 右寄せでFitすると、画像は右端に置かれ、残りは白になる
- [x] 横長の画像を縦長のモニターへFitすると、縦横比を保って上下中央に置かれる
- [x] 合成した画像は、モニターと同じ大きさのPNGファイルとして保存される
- [x] 同じモニターの古い合成画像は、新しい画像を作るときに削除される
- [x] 画像として読めないファイルを合成しようとすると、ImageComposeExceptionを投げる
- [x] ドロップすると、モニターの大きさと寄せ方で合成した画像が壁紙に設定される
- [x] 寄せ方の既定は左寄せである
- [x] 寄せ方を変えると、最後にドロップした画像で壁紙が作り直される
- [x] ドロップする前に寄せ方を変えても、壁紙は変わらない
- [x] 枠の寄せ方を右寄せに切り替えると、そのモニターの寄せ方が右寄せになる（View）

## 壁紙設定 > 変更 > フォルダを枠へドロップすると、フォルダが登録される

- [x] 保存したフォルダの登録は、読み込むと同じ内容で戻る
- [x] 設定ファイルがないとき、フォルダの登録は空である
- [x] フォルダを枠にドロップすると、そのモニターのフォルダとして登録され、保存される
- [x] フォルダをドロップしても、壁紙は変わらない
- [x] モニター一覧を読み込むと、保存されたフォルダの登録も各モニターに読み込まれる
- [x] 登録されたフォルダの名前が枠に表示される（View）

## 壁紙設定 > 変更 > フォルダをドロップすると、すぐにランダムな1枚を壁紙にする

- [x] フォルダの中の画像ファイルから、ランダムに1枚を選ぶ
- [x] 画像ファイルがないフォルダからは、何も選ばない
- [x] フォルダをドロップすると、フォルダの中からランダムに選んだ1枚が壁紙に設定される（「フォルダをドロップしても、壁紙は変わらない」を置き換える）
- [x] 画像のないフォルダをドロップすると、フォルダは登録されるが、壁紙は変わらない

## 表示 > ウィンドウ表示 > モニターのサイズと向きが枠に反映される

- [x] 枠の大きさは、モニターの大きさに比例する（縦置きのモニターの枠は縦長になる）
- [x] モニターが多いとき、全モニターの枠の合計幅は決まった幅に収まる
- [x] 枠は、ViewModelが計算した大きさで表示される（View）

## 表示 > ウィンドウ表示 > 現在の壁紙がサムネイルで表示される

- [x] モニター一覧を読み込むと、各モニターの現在の壁紙も読み込まれる
- [x] 壁紙が設定されていないモニターでは、現在の壁紙は空である
- [x] 画像をドロップして壁紙を変えると、そのモニターの現在の壁紙も変わる
- [x] 現在の壁紙が、枠のサムネイルに表示される（View）

## 不具合：再起動後、寄せ方を切り替えてもその場で反応しない

- [x] 保存したモニターごとの設定（フォルダ・元の画像・寄せ方）は、読み込むと同じ内容で戻る（「保存したフォルダの登録は…」を置き換える）
- [x] 設定ファイルがないとき、モニターごとの設定は空である（「設定ファイルがないとき、フォルダの登録は空である」を置き換える）
- [x] 画像をドロップすると、元の画像と寄せ方がモニターの設定として保存される
- [x] 寄せ方を変えると、その寄せ方が保存される
- [x] モニター一覧を読み込むと、保存された寄せ方が読み込まれ、壁紙は変わらない
- [x] 再起動後にドロップしていなくても、寄せ方を変えると、前回の元の画像で壁紙が作り直される
- [x] モニターが多いとき、枠は合計幅が決まった幅に収まる大きさで表示される（View）

## AtlantaFXの適用

- [x] 起動時にAtlantaFXのPrimer Lightテーマが適用されている

## 壁紙設定 > ランダム > ランダム変更ボタンを押すと、全モニターがランダムに変わる

- [x] ランダム変更すると、フォルダが登録された全モニターの壁紙が、それぞれのフォルダからランダムに選んだ画像になる
- [x] フォルダが登録されていないモニターの壁紙は、ランダム変更しても変わらない
- [x] ランダムに選んだ画像は、元の画像として保存される
- [x] ランダム変更ボタンを押すと、全モニターの壁紙がランダムに変わる（View）

## ランダム変更ボタンの配置

- [x] ランダム変更ボタンは、ウィンドウの左右中央に置かれる（View）

## 準備 > 起動 > ウィンドウなし起動オプションでは、フォルダからランダムに選んで書き変えて自動終了する

- [x] 「--randomize」オプションがあるとき、ウィンドウなしで起動する
- [x] オプションがないとき、ウィンドウありで起動する
- [x] ウィンドウなしの起動では、モニター一覧と設定を読み込んでから、全モニターの壁紙を登録フォルダからランダムに変える

## 壁紙設定 > 設定 > 埋める色を白か黒か選べる

- [x] 黒で埋めるようにFitすると、画像以外は黒になる
- [x] 保存した埋める色は、読み込むと同じ色で戻る
- [x] 埋める色が保存されていない設定ファイルでは、埋める色は白である
- [x] 埋める色の初期値は白である
- [x] 埋める色を変えると、前回の元の画像で壁紙が作り直される
- [x] 埋める色を変えると、その色が保存される
- [x] モニター一覧を読み込むと、保存された埋める色が読み込まれる
- [x] 枠の埋める色を黒に切り替えると、そのモニターの埋める色が黒になる
