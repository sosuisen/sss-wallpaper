# plans

## エラー表示 > ウィンドウありの起動で、回復できないエラーを画面に表示する

- [ ] ウィンドウありで起動したとき、例外を捕まえる仕組みがない。たとえば、壁紙の画像が壊れていて合成に失敗しても、画面には何も出ず、スタックトレースが出力されるだけである。スキルの`JavaFX-MVVM.md`に従い、`App.start()`で未捕捉例外のハンドラを登録し、エラーダイアログを出す
  - [ ] エラーダイアログのメッセージは、展開可能な領域に表示され、初期状態で展開されている
  - [ ] 想定外のエラーのダイアログには、例外のスタックトレースが読み取り専用で表示され、初期状態で展開されている
  - [ ] FXスレッドで回復できないエラー（`UnrecoverableException`）が起きると、そのメッセージのエラーダイアログが表示され、ウィンドウは開いたままである
  - [ ] FXスレッドで想定外の例外が起きると、その内容を含むエラーダイアログが表示される
  - [ ] 起動時にモニター一覧の読み込みに失敗すると、エラーダイアログが表示され、ウィンドウは開いたままである（例: 設定ファイルが読めない）
